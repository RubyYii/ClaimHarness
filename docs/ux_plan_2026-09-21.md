# Workbench usability update

The reported problem is that first-time users cannot easily decide where to start or what to do next. This change stays within the existing local workflow and limited evidence-check scope.

## Observed baseline

- Eight navigation entries, a six-step strip, introductory panels and module cards precede the home-page action buttons.
- Every interaction enumerates historical runs and verifies completion hashes for the unopened cleanup controls.
- The interview has five required answers, but previous answers cannot be edited until all five are complete.
- Technical filenames and output directories compete with the next useful action.

## Implementation brief

- Put a working synthetic example and three plain-language entry routes on the first screen.
- Keep the full tool list and project maintenance available in collapsed sections. Read historical runs only when their controls are requested.
- Make page introductions concise, with output details and limitations available in expandable help.
- Show the actual answered-field count, question-specific examples, and an edit-previous-answer action that preserves later answers.
- Offer resumption of valid current-project results, actionable empty states and a direct next action after generation.
- Preserve native keyboard controls, Chinese and English experiences, project identity, draft protection and the local deterministic default.

## Verification

Exercise the example, question-to-interview handoff, correction of earlier answers, project isolation and error recovery with Streamlit AppTest. Run the required CLI demo and complete pytest suite. Inspect the real browser at desktop and narrow widths, including keyboard access and screenshots.

Gemini design drafting was attempted before source edits but returned HTTP 429 (daily quota exceeded). Automatic approval review rejected external submission of the baseline screenshot because it contained a project ID and configuration text. Local browser inspection and a local-only visual smoke check are used; external visual judgement is unavailable.
