OCR 安装说明
OCR Setup Guide

OCR 是可选项。默认情况下，ProblemBridge / ClaimHarness 不需要 OCR。只有当你要读取扫描版 PDF 或图片文字时，才需要安装这一组工具。

Local only No API key Optional dependency Scans and images

默认资源门：单个来源 25 MB、最多 50 页、最多 1,000,000 个字符；单次操作超时 30 秒，PDF 以 150 DPI 逐页渲染，单页超过 20,000,000 像素会被拒绝。这些限制用于降低资源风险，不保证识别准确，也不等于恶意文件沙箱。

混合文字/扫描 PDF 不会自动合并：只要部分页面有直接文本、另一些页面没有文字层，系统会保留直接文本、列出无文本页，并以 mixed_pdf_requires_page_review fail closed。无文本页可能是扫描页，也可能本来就是空白页；请核对原件，把确认的扫描页拆成纯扫描 PDF 或图片后再单独 OCR。

1. 先装 Python OCR extra

在仓库根目录运行：

pip install -c requirements/constraints.txt -e ".[ui,ocr]"

这会安装 pytesseract、pdf2image 和 Pillow。这些只是 Python 包，还需要系统工具。

2. 按系统安装 OCR 工具

Windows

安装 UB-Mannheim 的 Tesseract Windows installer，并尽量使用默认路径：

C:\Program Files\Tesseract-OCR

扫描版 PDF 还需要 Poppler，并把 Poppler 的 bin 目录加入 PATH。

macOS

如果已经安装 Homebrew：

brew install tesseract poppler

Ubuntu / Debian

sudo apt update
sudo apt install tesseract-ocr poppler-utils
sudo apt install tesseract-ocr-chi-sim

3. 中文 OCR

如果要识别中文扫描件，需要 chi_sim 语言数据。否则中文可能乱码、漏字或识别成英文字符。

tesseract --list-langs

列表里至少应看到 eng。如果要识别简体中文，还要看到 chi_sim。

chi_sim 只提供粗略的中文字符识别；它不代表 ClaimHarness 的中文 claim 提取或验证已经通过评测。当前审计规则和合成回归集仍以英文为主。

4. 检查安装

tesseract --version
pdftoppm -h
tesseract --list-langs

如果 tesseract 或 pdftoppm 显示“not recognized / command not found”，说明系统工具还没装好，或没有加入 PATH。

5. 在本地 App 里使用

  1. 运行 streamlit run apps/problem_bridge_wizard.py。
  2. 打开 Document intake。
  3. 上传扫描版 PDF 或图片。
  4. 打开 Enable optional OCR for images and image-only PDFs。
  5. 在 OCR language 选择 eng、chi_sim 或 eng+chi_sim。本机必须安装对应 Tesseract 语言包；英文界面默认 eng，中文界面默认 eng+chi_sim，但不会自动检测文档语言。
  6. 生成文档摄取包。

生成后请检查 ocr_quality_report.json 中的引擎/版本、来源 SHA-256、逐页定位、失败/跳过页，以及字节、页数、字符数、超时、DPI 和像素限制。OCR 文本会标记为 derived_text/ocr；从这类输入提取的 claim 必须进入人工原件核对，不能仅凭 OCR 文本或 OCR 来源的“复核记录”满足强证据或人工批准要求。

常见问题

现象原因处理
找不到 tesseractTesseract 未安装或不在 PATH安装 Tesseract，重新打开终端或 App
找不到 pdftoppmPoppler 未安装或不在 PATH安装 Poppler，并把 bin 加入 PATH
中文识别很差缺少 chi_sim安装简体中文语言数据
出现 mixed_pdf_requires_page_review部分页有直接文本，部分页没有文字层检查报告列出的页码；把确认的扫描页拆开后单独 OCR 并人工核对
OCR 文本很乱扫描质量或版式复杂换更清晰扫描件，或把 OCR 当作粗略输入
边界：OCR 只提取可见文字，不理解图片、图表、医学/法律/教育判断，也不能替代人工复核。必须把提取文本与原件对照；中文 OCR 可用不等于中文 claim 审计已验证。
