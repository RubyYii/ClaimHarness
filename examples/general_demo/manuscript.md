# Synthetic Document Triage Benchmark

## Abstract

This invented document-triage example demonstrates table-based claim screening. The triage_reviewer model outperforms baseline_rules on macro F1 in the synthetic metric table. The model is robust across all document domains.

## Methods

All values are invented for a deterministic software demonstration. No documents were collected and no user evaluation was performed.

## Results

The triage_reviewer improves macro F1 from 0.70 to 0.82 in the synthetic benchmark. The triage_reviewer improves precision from 0.76 to 0.95 in the synthetic benchmark.

## Discussion

The accompanying table reports precision of 0.86. The precision claim above intentionally conflicts with that value. The cross-domain robustness claim has no external evidence. These invented values do not establish performance on actual documents.
